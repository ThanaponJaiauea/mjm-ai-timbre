## 🎹 ภาพรวม

**AcidSynth** คือเครื่องสังเคราะห์เสียงเบสสไตล์ **TB-303** ที่ทำงานบนเว็บเบราว์เซอร์

### คุณสมบัติหลัก:
- ✅ **Step Sequencer** 1-64 steps
- ✅ **Piano Roll Grid** แก้ไขโน้ตได้โดยตรง
- ✅ **Real-time Controls** ปรับค่าได้ทุกค่าขณะเล่น
- ✅ **Pattern Generator** สร้าง Pattern อัตโนมัติ
- ✅ **MIDI Export** ส่งออกโน้ตไปใช้กับ DAW อื่นได้
- ✅ **TB-303 Emulation** เสียง Acid Bass แบบคลาสสิก

## 🎮 วิธีการใช้งาน

### ขั้นตอนที่ 1: เริ่มต้น
```
1. เปิดหน้าเว็บ
2. กดปุ่ม [PLAY] เพื่อเริ่มเสียง
   (เบราว์เซอร์อาจขอสิทธิ์ใช้งานเสียงครั้งแรก)
```

### ขั้นตอนที่ 2: สร้าง Pattern
```
Option A - Auto Generate:
  • กด [GENERATE] → ระบบสร้าง Pattern ให้อัตโนมัติ

Option B - Manual:
  • คลิกบน Grid เพื่อเปิด/ปิดโน้ต
  • คลิก Lane ด้านล่างเพื่อเพิ่ม Slide/Accent
```

### ขั้นตอนที่ 3: ปรับเสียง
```
• หมุน Knob ต่างๆ เพื่อปรับเสียง
• ทุกค่าปรับได้แบบ Real-time (ขณะเล่น)
```

### ขั้นตอนที่ 4: บันทึก
```
• กด [Download MIDI] → ได้ไฟล์ .mid
• Import เข้า DAW (FL Studio, Ableton, etc.)
```

### 🎚️ Row 2: Synth Parameters (เสียง)

#### **LENGTH** (1-64)
```
ความยาวของ Pattern (จำนวน steps)

• 1-8  : Pattern สั้นๆ
• 16   : มาตรฐาน (1 ห้อง 4/4)
• 32   : Pattern ยาว 2 ห้อง
• 64   : Pattern ยาว 4 ห้อง

💡 ผลต่อเสียง: Pattern ยาว = โน้ตมากขึ้น, หลากหลายขึ้น
```

#### **CUTOFF** (0-127)
```
ความถี่ตัดของ Filter (Lowpass Filter)

• 0-30   : เสียงทึบ, มืด, อบอุ่น
• 31-60  : เสียงกลางๆ, สมดุล
• 61-90  : เสียงสว่าง, ชัดเจน
• 91-127 : เสียงแหลม, คมชัด

💡 ผลต่อเสียง: ค่าสูง = เสียงสว่าง, ค่าต่ำ = เสียงทึบ
🎵 เทคนิค: หมุนขึ้น-ลง ขณะเล่น ได้เสียง "Wah-Wah"
```

#### **RESONANCE** (0-127)
```
ความแหลมของ Filter Peak (Q-Factor)

• 0-30   : เรโซแนนซ์ต่ำ, เสียงนุ่ม
• 31-60  : เรโซแนนซ์ปานกลาง
• 61-90  : เรโซแนนซ์สูง, เสียงแหลมคม
• 91-127 : เรโซแนนซ์สูงสุด, เสียง "หอน"

💡 ผลต่อเสียง: ค่าสูง = เสียงแหลม "ปี๊ด", ค่าต่ำ = เสียงนุ่ม
🎵 เทคนิค: ค่าสูง + Cutoff สูง = เสียง Acid แบบคลาสสิก
```

#### **DRIVE** (0-100)
```
ความแตก/อิ่มตัวของเสียง (Distortion)

• 0-20   : สะอาด, ไม่มีแตก
• 21-50  : อิ่มตัวเล็กน้อย, อบอุ่น
• 51-80  : แตกปานกลาง, ดุดัน
• 81-100 : แตกมาก, รุนแรง

💡 ผลต่อเสียง: ค่าสูง = เสียงแตก, ดุดัน, ดังขึ้น
🎵 เทคนิค: ใช้กับ Accent เพื่อเสียงที่โดดเด่น
```

#### **MOD** (EnvMod) (0-127)
```
ความลึกของ Filter Envelope

• 0-30   : Filter ไม่ค่อยขยับ
• 31-60  : Filter ขยับปานกลาง
• 61-90  : Filter ขยับมาก
• 91-127 : Filter ขยับสูงสุด, Sweep กว้าง

💡 ผลต่อเสียง: ค่าสูง = Filter เปิด-ปิดกว้าง, เสียงไดนามิก
🎵 เทคนิค: ค่าสูง + Decay สูง = เสียง "วูบวาบ"
```

#### **DECAY** (0-127)
```
ความยาวของ Filter Sweep

• 0-30   : สั้น, กระชับ
• 31-60  : ปานกลาง
• 61-90  : ยาว, ลื่นไหล
• 91-127 : ยาวมาก, ค่อยๆ ลดลง

💡 ผลต่อเสียง: ค่าสูง = Filter ค่อยๆ ปิด, ค่าต่ำ = Filter ปิดทันที
🎵 เทคนิค: ค่าสูง = เสียง "วูบ" ยาวๆ
```

#### **ACCENT** (0-127)
```
ความแรงของ Accent Circuit

• 0-30   : Accent เบาๆ
• 31-60  : Accent ปานกลาง
• 61-90  : Accent ชัดเจน
• 91-127 : Accent แรงมาก

💡 ผลต่อเสียง: ค่าสูง = โน้ตที่มี Accent ดังกว่า, แหลมกว่า, แตกกว่า
🎵 เทคนิค: ใช้กับ Slide ได้เสียง "วูบ" ที่โดดเด่น
```

#### **BPM** (60-220)
```
ความเร็วของเพลง (Beats Per Minute)

• 60-80   : ช้า, Chill
• 81-120  : ปานกลาง, House
• 121-150 : เร็ว, Techno
• 151-180 : เร็วมาก, Acid House
• 181-220 : เร็วสุดๆ, Hardcore

💡 ผลต่อเสียง: ค่าสูง = เร็ว, ตื่นเต้น
```

#### **VOL** (0-1)
```
ระดับเสียงรวม (Master Volume)

• 0-0.3  : เบา
• 0.4-0.7: ปานกลาง
• 0.8-1.0: ดัง

💡 แนะนำ: ตั้งไว้ที่ 0.5-0.7 เพื่อป้องกันเสียงแตก
```

### 🎼 Row 3: Pattern Generator Controls

#### **Root** (C, C#, D, D#, E, F, F#, G, G#, A, A#, B)
```
โน้ตหลักของ Scale (Key)

• C  : โทน C
• D  : โทน D
• E  : โทน E
• F  : โทน F
• G  : โทน G
• A  : โทน A
• B  : โทน B
• ฯลฯ

💡 ผลต่อเสียง: กำหนดโทนของเพลง
🎵 เทคนิค: เลือกให้เข้ากับเพลงหลัก
```

#### **Scale** (15 โหมด)
```
โหมดเสียงที่ใช้สร้าง Pattern

| Scale | เสียง | อารมณ์ |
|-------|-------|--------|
| **Chromatic** | ทุกโน้ต | อิสระ, Jazz |
| **Major** | สดใส | มีความสุข |
| **Minor** | มืด | เศร้า, ลึกลับ ⭐ แนะนำ |
| **Dorian** | Minor + 6th | Modern, Funky |
| **Mixolydian** | Major + b7th | Blues, Rock |
| **Lydian** | Major + #4th | ฝัน, ลอย |
| **Phrygian** | Minor + b2nd | สเปน, ดุ |
| **Locrian** | Diminished | ตึงเครียด |
| **Harmonic Minor** | Minor + 7th | คลาสสิก, ตะวันออก |
| **Melodic Minor** | Minor + 6th, 7th | Jazz |
| **Pentatonic Major** | 5 โน้ต | ง่าย, ไพเราะ |
| **Pentatonic Minor** | 5 โน้ต | Blues, Rock |
| **Bhairav** | อินเดีย | ขลัง, ลึกลับ |
| **Spanish** | สเปน | ร้อนแรง |
| **Blue** | Blues | เศร้า, Soul |
| **Whole Tone** | ทุกโน้ตเต็มเสียง | ฝัน, ประหลาด |

💡 แนะนำ: **Minor** เหมาะกับ Acid House ที่สุด
```

#### **DENSITY** (0-100)
```
ความหนาแน่นของโน้ต

• 0-20   : โน้ตน้อย, เว้นว่างมาก
• 21-50  : โน้ตปานกลาง
• 51-80  : โน้ตเยอะ
• 81-100 : โน้ตแน่นมาก

💡 ผลต่อเสียง: ค่าสูง = โน้ตเยอะ, ยุ่ง, ตื่นเต้น
🎵 เทคนิค: 50-70 กำลังดีสำหรับ Acid House
```

#### **ACCENT %** (0-100)
```
ความน่าจะเป็นที่โน้ตจะมี Accent

• 0-20   : Accent น้อยมาก
• 21-40  : Accent น้อย
• 41-60  : Accent ปานกลาง ⭐ แนะนำ
• 61-80  : Accent บ่อย
• 81-100 : Accent เกือบทุกโน้ต

💡 ผลต่อเสียง: ค่าสูง = โน้ตส่วนใหญ่ดัง, เด่น
🎵 เทคนิค: 30-40% กำลังดี ได้จังหวะโยก
```

#### **SLIDE %** (0-100)
```
ความน่าจะเป็นที่โน้ตจะมี Slide

• 0-20   : Slide น้อยมาก
• 21-40  : Slide น้อย
• 41-60  : Slide ปานกลาง
• 61-80  : Slide บ่อย
• 81-100 : Slide เกือบทุกโน้ต

💡 ผลต่อเสียง: ค่าสูง = โน้ตไหลลื่น, ต่อเนื่อง
🎵 เทคนิค: 20-30% กำลังดี ได้ลูกเล่นพอดี
```

#### **SPREAD** (0-100)
```
ความหลากหลายของโน้ต (ช่วงเสียง)

• 0-20   : เล่นแค่โน้ตใกล้ๆ Root
• 21-50  : เล่นโน้ตช่วงกลาง
• 51-80  : เล่นโน้ตกว้าง
• 81-100 : เล่นทุกโน้ตใน Scale

💡 ผลต่อเสียง: ค่าสูง = โน้ตวิ่งทั่ว Scale, หลากหลาย
🎵 เทคนิค: 40-60 กำลังดี ไม่ต่ำไม่สูงเกินไป
⚠️ หมายเหตุ: ฟีเจอร์นี้ยังไม่ได้ใช้งานในเวอร์ชันปัจจุบัน
```

#### **Creeper** (ON/OFF)
```
โหมดสุ่มเปลี่ยนแปลง Pattern อัตโนมัติ

• **OFF** : Pattern คงที่
• **ON**  : Pattern เปลี่ยนแปลงเองตลอดเวลา

💡 ผลต่อเสียง: ได้ Pattern ไม่ซ้ำ, สร้างสรรค์
🎵 เทคนิค: ใช้ตอนหาไอเดียใหม่ๆ
⚠️ คำเตือน: Pattern จะเปลี่ยนไปเรื่อยๆ ไม่คงที่
```

## 🎹 Piano Roll Grid

### ส่วนประกอบ:

```
┌─────────────────────────────────────────┐
│  Note Labels  │  Grid (โน้ต)            │
│  (ซ้าย)       │  • คลิก = เปิด/ปิดโน้ต  │
│               │                         │
├───────────────┼─────────────────────────┤
│  O: Octave    │  U = Octave +1          │
│               │  D = Octave -1          │
├───────────────┼─────────────────────────┤
│  S: Slide     │  ■ = มี Slide           │
├───────────────┼─────────────────────────┤
│  A: Accent    │  ■ = มี Accent          │
├───────────────┼─────────────────────────┤
│  N: Number    │  1,2,3... = Step ที่    │
└───────────────┴─────────────────────────┘
```

### การใช้งาน:

| การกระทำ | ผล |
|---------|-----|
| **คลิกบน Grid** | เปิด/ปิดโน้ต |
| **คลิก Lane O** | เปลี่ยน Octave (0 → +1 → -1 → 0) |
| **คลิก Lane S** | เปิด/ปิด Slide |
| **คลิก Lane A** | เปิด/ปิด Accent |
| **คลิก Lane N** | ดูหมายเลข Step และชื่อโน้ต |

## 🔧 FAQ

### Q: ทำไมเสียงไม่ออก?
**A:** 
1. ตรวจสอบว่ากด [PLAY] แล้ว
2. ตรวจสอบ Volume (VOL Knob)
3. เบราว์เซอร์อาจขอสิทธิ์ใช้งานเสียงครั้งแรก

### Q: ทำไมเสียงแตกมาก?
**A:**
1. ลด DRIVE ลง (0-30)
2. ลด VOL ลง (0.5-0.7)
3. ลด RESONANCE ลง

### Q: ทำไมเสียงทึบเกินไป?
**A:**
1. เพิ่ม CUTOFF ขึ้น (60-90)
2. เพิ่ม MOD ขึ้น (50-80)

### Q: Pattern ไม่เปลี่ยนเลย?
**A:**
1. กด [GENERATE] เพื่อสร้าง Pattern ใหม่
2. ตรวจสอบว่า Creeper เปิดอยู่ (ถ้าต้องการให้เปลี่ยนอัตโนมัติ)

### Q: ไฟล์ MIDI เสียงไม่เหมือนในเว็บ?
**A:**
- **ปกติ!** MIDI เก็บแค่โน้ต ไม่เก็บเสียง Synth
- **วิธีแก้:** Import MIDI เข้า DAW + ใช้ TB-303 Plugin (เช่น jc303, Phoscyon)

### Q: จะบันทึกเสียงเป็น MP3/WAV ได้อย่างไร?
**A:**
1. ใช้โปรแกรมอัดเสียง (OBS, Audacity, etc.)
2. อัด Output จากเบราว์เซอร์
3. หรือ Export MIDI → ใช้ DAW Render เป็น Audio
